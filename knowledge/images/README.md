## Visual takeaways for STAR//FALL

- Use silhouette before detail: a Lancer should read as a long, sharp shape; a Mender should read as a support node.
- Use color to reinforce role, but also vary geometry and animation for color-blind readability.
- Reserve the brightest contrast for the player, active threats, pickups, and hit confirmation.
- Show the danger area before the damage frame.
- Keep the HUD quiet while the playfield is busy.
